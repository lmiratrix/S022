16  Prediction and Visualization with Models

To make nice plots of the predictions from models that have complex curves and relationships, the easiest way is to use the model to predict values for different covariate combinations, store all of this in a dataframe, and then use ggplot to plot your results using geom_line which will give you nice smoothed curves through the points. This document highlights some useful methods for doing this. We need the tidyverse and the modelr package

Prediction, and making plots from predictions, are foundational skills for data analysis, especially as models become more complex and interactions or non-linear terms are introduced.

We will use the iris dataset, as it has some strong relationships that make the ideas behind these tools more salient. Here is the raw data:

ggplot(iris, aes(x=Petal.Length, y=Petal.Width, col=Species)) +
  geom_point()

To visualize we go through a series of steps:

  1. Fit a model to describe the relationship between variables
  2. Generate a grid of values to predict over
  3. Add predictions to the grid
  4. Make the vizualization, plotting our predictions vs. our grid values.

Related reading: R for Data Science (1st Edition), Section 23.3 (Sections 23.1 and 23.2 are optional but helpful)

16.1 Fit a model

We first fit a a model to describe how petal length can be predicted by petal width and species. Our model allows the length-width relationship to be different for the different species.

M1 <- lm(Petal.Length ~ Petal.Width * Species, data=iris)

16.2 Generate a Prediction Grid

We often want to understand what our model is saying by predicting outcomes over combinations of input variables. We do this by first making a new dataset of the combinations of inputs we want to explore, and then we use our fit model to predict for all these combinations.

data_grid(), in the modelr package, is the tool for this. It will generate a simple dataframe with one row for each possible combination of variables you want. We will then predict for each of these rows.

Here is a toy example: see how duplicates are removed:

library( modelr )
my.df = data.frame( A=c(1,2,1,2), B=c(10,20,20,20), C=c(10,20,30,40) )
data_grid( my.df, A, B )
# A tibble: 4 × 2
      A     B
  <dbl> <dbl>
1     1    10
2     1    20
3     2    10
4     2    20

For our actual data we have:

grid = iris %>%
  data_grid( Petal.Width, Species )

my.df = data.frame( A=rnorm(1000), B=rexp(1000), C=rnorm(1000,mean=5) )
data_grid( my.df, 
           A=seq_range(A,n=3),
           B=seq_range(B,n=3) )

16.3 Add Predictions to the Grid

This is easy, like so:

grid <- grid %>% 
  add_predictions(M1)
head(grid)
# A tibble: 6 × 3
  Petal.Width Species     pred
        <dbl> <fct>      <dbl>
1         0.1 setosa      1.38
2         0.1 versicolor  1.97
3         0.1 virginica   4.31
4         0.2 setosa      1.44
5         0.2 versicolor  2.16
6         0.2 virginica   4.37

16.4 Plot Predicted Trends

We can then plot our predictions for each of our species:

ggplot(grid, aes(x=Petal.Width, y=pred, 
                 col=Species, group=Species)) +
  geom_line()

16.5 Extensions

16.5.1 Residuals and Diagnostics

We can add residuals to our data for model diagnostics:

iris <- add_residuals(iris, M1)
ggplot(iris, aes(x=Petal.Width, y=resid, col=Species)) +
  geom_jitter() +
  geom_ref_line(h=0, col="orange", size=0.5)

16.5.2 Multiple Models

Let’s try multiple models and compare their predictions. We will have a simple model with no interactions, and a more complex one that allows curved relationships within each species.

M0 <- lm( Petal.Length ~ Petal.Width + Species, data=iris )
M2 <- lm( Petal.Length ~ Species *(Petal.Width + I(Petal.Width^2)), data=iris )

grid = iris %>%
  data_grid( Petal.Width, Species ) %>%
  gather_predictions( M1, M0, M2 )
grid

16.5.3 Fancy Plotting with spread_predictions

The spread_predictions() function can be used to make each model a separate column:

grid <- iris %>%
  data_grid( Petal.Width, Species )
grid_spread = spread_predictions(grid, M0, M1)

16.6 Handy Functions Recap

Function Use
data_grid() Create a grid of input values for prediction
add_predictions() Add predicted values from a model to a dataset
add_residuals() Add model residuals to original data
gather_predictions() Combine predictions from multiple models for plotting
spread_predictions() Spread predictions into separate columns
seq_range() Create evenly spaced values over a variables range

16.7 Final Thoughts

These techniques make model interpretation and communication much easier. Being able to visualize predictions and model trends can bring clarity, especially when dealing with interactions or nonlinearities.

Practice using these tools and adapt them to your own datasets!
