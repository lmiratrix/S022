Author

17.1 Fitting the model on our data

We are going to show how to fit a model and then make plots of the model fit. This is a useful skill, especally when the model gets more and more complex.

First load the data and drop a bunch of variables we are not going to be using. Note how the pipe flows from load data to drop X to drop all the empathy variables.

emp = read.csv( "data/empathy_data.csv", as.is=TRUE ) %>% 
  select( -X, -starts_with("empathy" ) )
head( emp )
  grade age female  race schid
1     7  12      1 Other     1
2     7  13      1 Black     1
3     7  12      1 Asian     1
4     7  13      1 Black     1
5     7  12      0 Black     1
6     7  12      0 White     1

For illustration, we are going to investigate the incredibly uninteresting relationship between age and grade. Here is our raw data

ggplot( data=emp, aes( x=grade, y=age ) ) +
    geom_jitter()
Warning: Removed 410 rows containing missing values or values outside the scale range
(`geom_point()`).

Let’s fit a simple model:

M0 <- lm( age ~ grade * female, data=emp )

17.2 Prediction and Model Vizualization

Now we can use our model to predict. We are going to use some stuff from the modelr package which helps with this kind of activity.

First load modelr and then make all combos of grade and gender:

library( modelr )
grid = emp %>% data_grid( grade, female  )
grid

This is a new, fake, dataset. We can use it to predict what we would expect to see as an outcome for each case (row) in this set. We get one prediction for each row in our new data.

predict( M0, newdata=grid )

We can be a bit more clever, using more magic from the tidyverse. The following code adds a new column to our grid dataframe with predictions for each entry.

grid <- grid %>% add_predictions( M0 ) 
head( grid )
# A tibble: 6 × 3
  grade female  pred
  <int>  <int> <dbl>
1     6      0  11.6
2     6      1  11.4
3     6     NA  NA  
4     7      0  12.6
5     7      1  12.4
6     7     NA  NA

Our mini-dataset of predictions makes it super easy to plot trends (we first make female a factor so it doesn’t give a continuous color axis)

grid$female = as.factor( grid$female )
ggplot( grid, aes( x=grade, y=pred, col=female, group=female ) ) + geom_line()
Warning: Removed 10 rows containing missing values or values outside the scale range
(`geom_line()`).

17.3 Residuals

We can also add residuals to our original data:

emp <- add_residuals( emp, M0 )
head( emp )
  grade age female  race schid      resid
1     7  12      1 Other     1 -0.3866544
2     7  13      1 Black     1  0.6133456
3     7  12      1 Asian     1 -0.3866544
4     7  13      1 Black     1  0.6133456
5     7  12      0 Black     1 -0.5609714
6     7  12      0 White     1 -0.5609714

This allows for diagnostic plots

ggplot( emp, aes(x=grade, y=resid, col=female ) ) + geom_jitter() +
    geom_ref_line(h=0)
Warning: Removed 438 rows containing missing values or values outside the scale range
(`geom_point()`).

17.3.1 Commentary

We could have also made our dataset by hand. For example, we could do something like this:

another_grid = data.frame( grade=seq( 1,5, length.out=10 ), female=0 )

This allows us to put in values that we didn’t necessarily have in our original dataset. The data_grid is a very convienent way to avoid doing this.

17.3.2 Bonus weirdness

If you have multiple models you want to compare, you might try these commands

M0 <- lm( age ~ grade, data=emp )
M1 <- lm( age ~ grade * female, data=emp )
M2 <- lm( age ~ grade * female + I(grade^2), data=emp )
grid <- data_grid( emp, age, female )
grid <- spread_predictions( emp, M0, M1, M2 )
